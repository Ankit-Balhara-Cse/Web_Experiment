# EventHub - Event Management Website

## Assignment: Experiment 4 | Web Development Laboratory | Semester IV

## How to Run

1. Install Flask:
   ```
   pip install flask
   ```

2. Run the app:
   ```
   python app.py
   ```

3. Open browser and go to: `http://127.0.0.1:5000`

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home / Landing page |
| `/events` | Browse all events with search & filter |
| `/register` | Register for an event |
| `/admin` | Admin login & panel |

## Admin Panel
- **Password:** `admin123`
- Add, Edit, Delete events from `/admin`

## Features
- Responsive design (mobile-friendly)
- Live search on events page
- Category filter buttons
- JavaScript form validation on registration
- RSVP counter per event
- Flask session-based admin login
- Flash messages for feedback
